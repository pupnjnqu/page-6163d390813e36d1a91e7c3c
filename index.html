品牌名中的 ADSL 作为标识，强调接入体验应像传统专线一样可预期：开通后复制订阅、导入客户端、选择节点即可使用。线路包含普通节点池与 IPLC 专线优化节点，按套餐开放。官网套餐价格与流量配额公开列出，不捆绑隐藏项目。

使用场景

流媒体与内容访问

旗舰版与团队版强调全节点原生解锁，适合连续播放常见海外影音平台。基础版提供基础解锁，满足偶尔点播。建议在客户端中选择标注流媒体的节点，并保持订阅定期更新。

游戏与实时对战

需要更低抖动时，优先使用旗舰版 IPLC 专线游戏加速优化节点。团队版 VIP 高带宽节点适合多人对战或语音同时在线。游戏加速仍取决于本机网络与对端服务器，合理选择区域节点即可。

远程办公与协作

跨境会议、网盘同步、代码仓库与文档协作可走稳定中转。团队版支持企业定制路由，可将办公域名与娱乐流量分开，减少会议卡顿。

多设备随身使用

同一订阅可在电脑、手机与平板间切换。请遵守套餐设备上限，避免同一账号在过多终端同时连接导致限速。出门前在客户端完成一次成功连接测试即可。

配置流程（重点）

两元机场(ADSL)把操作收敛为五步，无需手工填写复杂服务器参数。完成一次导入后，之后只需更新订阅。

第一步：在官网确认套餐

对照流量、设备数与线路类型选择基础版、旗舰版或团队版。年付适合长期使用。支付完成后进入用户中心，即可看到专属机场订阅地址。

第二步：复制订阅链接

订阅一般为 Clash / 通用订阅 URL。请只在本机或受信设备粘贴，不要把链接发到公开群组。如需重置订阅，在用户中心重新生成即可使旧链接失效。

第三步：安装对应客户端

Windows 常用 Clash Verge 或 v2rayN；macOS 可用 Clash Verge 或 Stash；iOS 常用 Shadowrocket 或 Quantumult X；Android 可用 Clash Meta 类应用。请从应用商店或开发者官方发布页获取安装包。

第四步：一键导入配置

打开客户端的「从 URL 导入 / 添加订阅」，粘贴链接并命名为「两元机场」。导入成功后会看到节点列表。开启系统代理或 VPN 模式，按需选择规则分流（建议国内直连、海外走代理）。

第五步：测速选点并保持更新

先用延迟测试筛选节点，再访问目标网站确认解锁与速度。建议每周更新一次订阅以同步节点变更。连接异常时依次检查：本地网络、系统时间、客户端版本、订阅是否过期。

常见问题

如何在两元机场(ADSL)开通并开始使用？

在官网选择套餐并完成支付后，进入用户中心复制机场订阅链接，按本页配置流程导入 Clash、Shadowrocket 等客户端，选择节点连接即可。全过程不需要手工填写服务器地址与端口。

三个套餐应该怎么选？

轻度浏览与基础流媒体选基础版（100GB / 3 设备）。需要原生解锁、游戏 IPLC 与优先工单选旗舰版。多人共用、大流量或需要定制路由选团队版。年付按十个月计费，适合确认长期使用后再选。

流量如何计算，用完会怎样？

流量按套餐周期内实际代理流量累计，本地直连不计入。用尽后新连接会失败或被限速，可在用户中心升级套餐或等待周期重置。建议在客户端开启流量提醒，避免后台更新消耗额度。

能否解锁常见流媒体？游戏延迟如何？

基础版提供基础解锁；旗舰版与团队版为全节点原生流媒体解锁。游戏方面，旗舰版含 IPLC 专线优化，团队版另有 VIP 高带宽节点。实际体验仍与您当地宽带及目标区服有关，建议先测延迟再固定节点。

订阅导入失败或无法连网怎么办？

依次核对：链接是否完整、客户端是否最新、系统时间是否准确、是否超出设备数。可尝试更换节点或切换规则模式。仍失败时，旗舰版与团队版可通过工单提交客户端名称、系统版本与错误截图说明。

名称里的 ADSL 是什么意思？是否需要拨号？

ADSL 是品牌标识，用来表达「接入应稳定可预期」，并非要求您使用家用 ADSL 拨号。服务运行在现代加密隧道与专线节点上，手机流量与普通宽带均可导入客户端使用。

客户端必须从哪里下载才安全？

请使用各客户端开发者官网或系统应用商店的正式版本。两元机场(ADSL)官网只提供订阅与配置说明，不托管破解包或来源不明的一键包。导入后请检查系统代理端口是否被其他软件占用。
